# Jack 3D Portfolio

A modern, responsive 3D Creator portfolio landing page built with React, TypeScript, Tailwind CSS, Framer Motion, and Vite.

## ✨ Features

- 🎨 Modern dark UI
- 📱 Fully responsive design
- ⚡ Smooth Framer Motion animations
- 🧲 Magnetic hover effects
- 🖼️ Scroll-based marquee gallery
- ✍️ Animated text reveal
- 📌 Sticky project cards
- 💨 Fast Vite development environment

## 🛠 Tech Stack

- React 18
- TypeScript
- Vite
- Tailwind CSS
- Framer Motion
- Lucide React

## 🚀 Getting Started

Clone the repository

```bash
git clone https://github.com/DevIsuruSampath/jack-3d-portfolio.git
```

Enter the project

```bash
cd jack-3d-portfolio
```

Install dependencies

```bash
npm install
```

or

```bash
bun install
```

Start the development server

```bash
npm run dev
```

or

```bash
bun run dev
```

Build for production

```bash
npm run build
```
